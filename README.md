# HEARD — IBD Companion

A polished single-page IBD companion built entirely with HTML, CSS, and vanilla JavaScript. The supplied `Overlay.png` is the full-screen background; every interface element is recreated as editable, accessible HTML and CSS.

## Run locally

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

No installation step or third-party dependencies are required.

## Available interactions

- Switch smoothly between chat and game modes.
- Type and send messages into a scrollable chat history.
- Open the companion menu or select a room widget.
- Collect practice stars in the temporary game view.
